# 레퍼런스 — 블링(vling) · 뷰트랩(Viewtrap)

1번 워크벤치 IA는 유지한다. 두 사이트에서 **우리 Job에 해당하는 장점만** 가져온다. 인플루언서 광고 마켓, 검색 횟수 과금, 시청자 성비처럼 우리 데이터에 없는 기능은 베끼지 않는다.

공식: [블링 vling.net](https://vling.net/) · [뷰트랩 app.viewtrap.com](https://app.viewtrap.com/)

---

## 블링에서 가져올 것

| 장점 | 우리 화면에 |
|------|-------------|
| **요즘 뜨는 / 조회 / 급상승**처럼 정렬이 본문 위 탭 | 요즘 뜨는 · 기여도 · VPH · 조회 |
| **고급 필터가 표 위에 고정** (국가, 업로드, 전체/롱폼/Shorts) | 같은 한 줄. 페이지를 밀어내지 않음 |
| **알고신 스코어 = 숫자 + 5단계** (매우 낮음~매우 높음) | 기여도를 0–100 스코어로도 보여 줌 |
| **행 = 썸네일 + 제목 + 조회 미니 그래프 + 채널 메타** | 빈 회색 박스 대신 스캔 가능한 행 |
| **제목 클릭 → 영상 상세** (페이지 이동이 아니라 검사기) | 오른쪽 패널 |
| **키워드를 더 구체적인 검색 문구로** | 황금키워드 (제목 n-gram) |
| 물음표로 지표 설명 | 기여도/성과도 툴팁 |

가져오지 않음: 캠페인·광고 단가, 데이터 다운로드 페이월, 브랜드 세이프티 토글, AI 시나리오 본문 생성(우리 Gemini는 나중에).

## 뷰트랩에서 가져올 것

| 장점 | 우리 화면에 |
|------|-------------|
| **기여도 / 성과도를 Great·Good·Normal 라벨**로 먼저 읽기 | 5단 배지. 숫자만 던지지 않음 |
| **라벨 ↔ 수치 토글** | `수치로 보기` |
| **등급 클릭이 곧 필터** (Good/Great만 보기) | 배지 클릭 필터 |
| **썸네일+제목이 결과의 주인공** | 행 왼쪽을 크게 |
| **구독자 규모와 무관한 성과**를 따로 둠 | 성과도 열 (VPH 기반 라벨) |
| 초심자도 다음 행동이 보임 | 행 옆 `이 문구로 검색` |

가져오지 않음: 검색 횟수 과금 UI, 제목/썸네일 복붙을 유도하는 카피, 없는 시청자 인구통계.
